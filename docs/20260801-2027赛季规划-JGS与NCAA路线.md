## 0. 一句话定性

**2027 不是"提升排名年",是"成绩簿定价年"。**
NCAA D1 教练可主动联系球员(含口头 offer)= 高二结束后的 **6 月 15 日** → 对 Class of 2029 就是 **2027-06-15**(已经 NCSA 官方页确认)。官方访校从高三学年前的 8 月 1 日(2027-08-01)开放。

## 1. 校准数据(2026-07-31 JGS 实测,Class of 2029 女子共 747 人上榜)

JGS 公式:**65% scoring differential**(滚动 365 天,取最好 75% 轮次,每轮=杆数−USGA course rating)+ 25% field 强度 + 10% 名次。无 head-to-head 项。
上榜门槛:365 天内 ≥4 场多日赛、≥8 轮;赛事须 USGA 评级球场、≥36 洞、≥4,500 码、无最大杆数规则。加拿大赛事原生收录。

| 位置 | Differential 门槛 | ≈最好轮次平均 | 参照 |
|---|---|---|---|
| 班内 Top 10 | ≤ −4.36 | 67–69 | 加拿大最强 2029:Maggie Zhang(BC)#9,−4.58 |
| 班内 Top 50 | ≤ −1.65 | 70–72 | |
| 班内 Top 100 | ≤ −0.35 | 71.5–73.5 | 安省对标:Andrea Lai(St. Thomas)#87,−0.65 |
| **她现在(72–76)** | ≈ −0.5 ~ +2.5 | | **约 100–400 名区间;压到 72–73 即逼近 Top 100–150** |

NCSA 招募基准:**≤75 = 高端 D1 讨论区间;≤80 = 中低端 D1;≤85 = D2/顶级 NAIA**。教练只看 ≥6,000 码、≥36 洞多日赛,首选参考就是 JGS。
House v. NCAA 和解(2025-06)后:opt-in 学校取消 6.0 上限改 **roster limit 9**,但极少给满额,roster 收缩约 10% → **目标名单要下探到排名 100–150 的项目并纳入 D2**。女子高尔夫 D1 国际球员占比 20.1%,教练习惯跨境招募。

**三个 KPI:① 认证赛事 scoring average 压进 75、冲 73;② 单轮 80+ ≤ 全年轮次 15%;③ JGS 班内 Top 100(副产品)。**

## 2. 选赛三关(每场必答)

1. **收录关**:JGS/WAGR 收不收(标准见上)。不收录的只用于练兵。
2. **球场关**:≤6,000y 优先、无强制长 carry、par 5 可舒服三上、rating 别太低。
3. **下行关**:比较最坏情况——打爆的代价(排名/报名费/旅途/信心)可承受吗?

## 3. PBE 星规则(ajga.org 官方,2026-08 版)

- 入场机制 = **优先级排序**:Fully Exempt(全国大赛顶级名次)> 星多者优先。没有"够 N 颗必进",星越多越稳。
- **星有效期两年**:当年赚的星用到次年年底(2026 秋赚的星 2027 全年有效)→ 秋季攒星直接为 2027 服务。
- 2022 年起**进正赛不扣星**。会员注册/续费本身送 1 星。
- **Junior All-Star 年龄线:赛事年 1 月 1 日不得超过 14 岁** → 她 2027 无论生日都只剩 **Open + Qualifier** 两条路。
- Qualifier:$95,单轮,非会员可报,晋级抵扣正赛 $295;正赛前一天同场进行。
- 每场赛事(含非 AJGA)的星值在 PBE Schedule 该场的 "PBE Status" 下拉可查。

## 6. Recruiting 线(与比赛线并行)

- [ ] JGS profile 完整、逐场核对收录;拍 90 秒 swing video(四类杆 + 双机位)
- [ ] 2026-12 前定目标学校 20 所(冲 5/稳 10/保 5,按 House 后格局下探到 100–150 名 + D2)
- [ ] 2027-01~03 首轮教练邮件(成绩 + 视频 + 未来参赛表);出分后二轮跟进
- [ ] **2027-06-15** D1 可联系;**2027-08-01** 起可官方访校
- [ ] NCAA Eligibility Center 注册(国际生 $160,D1/D2 学业+业余双认证;D3 也要业余认证)
- [ ] 业余身份:入学前奖金限制已取消(Brantmeier 和解),但保留参赛/奖金凭证
